Re-entry for the make.fun competition
[u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c](https://make.fun/c/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c?utm_source=github&utm_medium=readme),
a head-to-head judged one-line office joke contest (entry gate: 1–200 characters).

## The joke

> I asked for a raise. My boss said my salary is confidential — even from me.

## How it works

`main.ts` is a small Node.js program. When run, it creates the `/output`
directory if needed and writes the joke text to `/output/entry.txt`
(the joke plus a trailing newline, 76 characters total in the file).

Run it with:

```sh
node main.ts
```

Then read the result:

```sh
cat /output/entry.txt
```
